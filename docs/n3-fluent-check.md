# N3 fluent check: what to look at in the playtest

Kotoba Party's N3 line (the Limited Express) was built before a fluent speaker checked it. Please mark each row while you play or read. In **Natural?** write ✓, ✗ or "odd". In **Notes**, write a better way to say it, or anything a learner shouldn't copy. Short notes are fine.

## 1. Patterns the game guesses at

These six look like other patterns, so the game uses a narrow rule to decide when you've said one. The left column is what it counts; the next is what it doesn't. Please tell us if a line on the left is unnatural, if a line on the right should count, or if you'd say the pattern in a way we'd miss. In **Should it count?**, say whether the game should credit this pattern at all.
