# Contributor notes

## Commercial blockers

The game may be sold one day. [docs/commercial-blockers.md](docs/commercial-blockers.md) logs every
decision, dependency, asset or service that would stop that or add conditions to it.

- When you add a library, dataset, voice, font, image, model, API or hosting plan, or make a decision
  that limits selling, add or update a row there in the same PR: what it is, where it's used, its
  status, why, and what it takes to clear it.
- Record the terms' URL and the date you read them. If you couldn't read them, mark the row ❓ and say
  so; don't guess.
- If something is a ⛔ blocker, say so in the PR description too.
